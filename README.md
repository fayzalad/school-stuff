# school-stuff

Study material.

## WRAV102 Theory Drill

100 multiple-choice questions for WRAV102 / MSEV102 Semester Test 2,
covering the Section A theory topics:

1. Sorting algorithms (bubble, selection, insertion)
2. Searching and sorted state (linear vs binary)
3. Classes, list classes, arraylists, arrays, text files, position rules
4. Code tracing and applied questions

Answers save to your browser, so you can close the page and come back
to the same place. Four tabs, 25 questions each.

## ICNF102 Field Reference

A 21-sheet study guide covering the whole Communication Network Fundamentals
module — communication rules, OSI/TCP/IP models, physical and data link
layers, IP addressing, subnetting and VLSM, transport and application layers,
DHCP, NAT, VLANs, routing and RIPv2 — plus a reference appendix and a
walkthrough of the module case study. Every sheet ends in a self-test.

**[Open the guide](https://fayzalad.github.io/school-stuff/icnf102-study-guide/)**

## ICNF102 Line Test

200 multiple-choice questions for ICNF102, split into 8 sets of 25 that rise
in difficulty. Study mode explains each answer as you go; Test mode holds
feedback until the end of the set. Every question carries a full explanation,
so it doubles as revision.

**[Open the quiz](https://fayzalad.github.io/school-stuff/icnf102-quiz/)**
