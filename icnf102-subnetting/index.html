How traditional subnetting works — the short version

Every IPv4 address has a default class, and each class has a default (classful) mask. Traditional subnetting starts from that default mask and borrows bits from the host portion to create equal-sized subnets.

ClassFirst octetDefault maskDefault prefix
A1 – 126255.0.0.0/8
B128 – 191255.255.0.0/16
C192 – 223255.255.255.0/24

The four things every problem asks for, in order:

1. Bits to borrow (n) — smallest n where 2^n >= subnets needed 2. New prefix = default prefix + n → convert to a dotted-decimal mask 3. Usable hosts per subnet = 2^(32 − new prefix) − 2 4. Each subnet's network address = previous network + block size, where block size = 2^(32 − new prefix)
