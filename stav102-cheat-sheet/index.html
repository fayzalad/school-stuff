Discrete table

Missing k: Σp = 1.   E(X) = Σx·p   V(X) = Σx²p − μ²

V(aX + b) = a²V(X). V(X ± Y) = V(X) + V(Y) (independent). Variances always add.

Binomial properties (list 3)

  • fixed number of trials n
  • two outcomes (success/failure)
  • p constant every trial
  • trials independent

Poisson properties (list 3)

  • counts events in an interval (time/space)
  • independent across non-overlapping intervals
  • P(event) same for equal intervals, ∝ interval size
  • 2+ events in a tiny interval ≈ impossible

Normal

N(μ, σ²) — square-root the variance!

z = (x − μ)/σ, round to 2 dp. Table = area to the LEFT.

P(Z > z) = 1 − P(Z < z)
P(Z < −z) = 1 − P(Z < z)
P(Z > −z) = P(Z < z)

P(−a < Z < b) = P(Z < b) + P(Z < a) − 1

Inverse: make it "P(Z < z) = area"; if area < 0.5, z is negative. x = μ + zσ.

Empirical rule: 68 / 95 / 99.7% within 1 / 2 / 3 σ.

One value or an average?

"a randomly selected …" → σ

"the mean of a sample of n …" → σ/√n (standard error)

CLT: x̄ ≈ normal if n ≥ 30 (exact if population normal).

p̂ ~ N(p, p(1−p)/n) if np > 5 and n(1−p) > 5. Use the claimed p in the SE.
