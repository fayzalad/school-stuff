IAUT202 — PLC scenario practice (6 scenarios)

Six packaging and conveyor scenarios in the style of Question 3 (25 marks): carton line, crate line, labeller, shrink-wrap tunnel, two-conveyor accumulator and pallet layer counter. Do each one on paper, then open the memo.

Scenario 1 · 25 marks

Carton packaging line

Tins arrive on an infeed conveyor and are packed 12 to a carton. Use only these LOGO!-style blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay. Inputs: I1 Start (NO pushbutton), I2 Stop (NO pushbutton, pressed = 1), I3 tin sensor (one pulse per tin), I4 carton in position, I5 Reset pushbutton. Outputs: Q1 infeed conveyor, Q2 carton conveyor, Q3 sealer, Q4 green lamp, Q5 red lamp.

  1. Start latches the line on; Stop switches it off (Stop wins). The green lamp is on while the line is on.
  2. The infeed conveyor runs only while the line is on, a carton is in position and the carton is not yet full.
  3. Tins are counted. After 12 tins the carton is full.
  4. When the carton is full, the sealer operates for 4 s.
  5. When sealing is complete, the carton conveyor runs for 5 s to take the carton away, then the counter is reset. The red lamp flashes at 1 Hz while the carton conveyor runs.
  6. The Reset button also clears the counter at any time.

Draw the carton-conveyor logic and the 1 Hz red flasher.

BlockLogic
M2 latchSet = T1 output (sealing finished), Reset = T2 output

The flasher works because T3 comes on after 0.5 s, T4 comes on 0.5 s later and cuts T3 off, which cuts T4 off, so the cycle repeats every 1 s. Marks: latch (2), 5 s timer and resets (2), Q2 (1), flasher (3).

Scenario 2 · 25 marks

Bottle crate packing line

Bottles are packed 24 to a crate. Use only these LOGO!-style blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay. Inputs: I1 Start, I2 Stop, I3 bottle sensor (one pulse per bottle), I4 crate in position, I5 Reset, I6 Emergency stop (all pushbuttons: pressed = 1). Outputs: Q1 bottle conveyor, Q2 crate conveyor, Q3 red lamp (crate full), Q4 amber lamp (crate nearly full), Q5 green lamp (running).

  1. Start latches the line on. Stop or Emergency stop switches it off. The green lamp shows the line is on.
  2. The bottle conveyor runs only while the line is on, a crate is in position and the crate is not full.
  3. From bottle 20 to bottle 23 the amber lamp is on. At 24 bottles the crate is full: the amber lamp goes off and the red lamp comes on.
  4. 3 s after the crate is full the crate conveyor runs for 6 s to remove it. After that the counters are reset.
  5. Reset clears both counters at any time.

Scenario 3 · 25 marks

Box labelling line

Boxes travel on a conveyor to a labeller. Use only these LOGO!-style blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay. Inputs: I1 Start, I2 Stop, I3 box at the labeller (photoelectric sensor), I4 label applied (sensor), I5 Fault reset (all pushbuttons: pressed = 1). Outputs: Q1 conveyor, Q2 labeller, Q3 green lamp, Q4 red alarm lamp.

  1. Start latches the line on; Stop switches it off. The green lamp is on while the line is running without a fault.
  2. The conveyor runs while the line is on and no box is at the labeller.
  3. 1 s after a box arrives at the labeller, the labeller starts and runs until the label-applied sensor sees the label.
  4. If the label is not applied within 4 s of the labeller starting, a fault latches: the line stops and the red lamp flashes at 1 Hz until Fault reset is pressed.

M2 fault latchSet = T2 output, Reset = I5

I/O table (5 marks), latches and Run (6), conveyor and labeller with the 1 s delay (6), 4 s fault timer and latch (4), flasher (4). When the fault latches, Q3 drops, so Q2 stops and T2 resets; the fault stays latched until I5.

Scenario 4 · 25 marks

Shrink-wrap tunnel

Packs pass through a heated shrink-wrap tunnel. Use only these LOGO!-style blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay. Inputs: I1 Start, I2 Stop, I3 pack sensor (one pulse per pack leaving), I4 Reset (pushbuttons: pressed = 1). Outputs: Q1 tunnel conveyor, Q2 heater, Q3 cooling fan, Q4 batch lamp.

  1. Start latches the line on; Stop switches it off.
  2. The heater comes on with the line. The conveyor starts 3 s after the heater so the tunnel is hot first.
  3. The cooling fan runs while the heater is on and for 10 s after the heater goes off.
  4. Packs leaving the tunnel are counted while the conveyor runs. After 50 packs the batch lamp comes on until Reset is pressed.
Show memo

Make an I/O table and draw (or write as equations) the complete logic.

BlockLogic
M1 run latchSet = I1, Reset = I2
Q2 heaterQ2 = M1
T1 on-delay 3 sInput = M1
Q1 conveyorQ1 = T1 (it drops the moment M1 drops)
T2 off-delay 10 sInput = Q2; Q3 = T2 output (on with the heater and 10 s after)
C1 up counter, preset 50Cnt = I3 · Q1, Reset = I4; Q4 = C1

I/O table (5 marks), latch and heater (4), conveyor delay (5), fan off-delay (5), counter with the gate and reset (6). The off-delay is the key block: an on-delay cannot keep an output on after its input is gone.

Scenario 5 · 25 marks

Two-conveyor accumulator

Two conveyors in series, the second feeding a packer. Use only these LOGO!-style blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay. Inputs: I1 Start, I2 Stop, I3 overload on either motor (stays 1 while the overload exists). Outputs: Q1 infeed conveyor, Q2 packer conveyor, Q3 green lamp, Q4 red lamp.

  1. Start latches the line on; Stop or an overload switches the line off.
  2. On starting, the packer conveyor runs first and the infeed conveyor follows 5 s later.
  3. On stopping, the infeed stops at once and the packer conveyor runs 5 s longer to clear the line.
  4. An overload stops both conveyors at once. The green lamp shows the line is on; the red lamp is on while an overload exists.
Show memo

Make an I/O table and draw (or write as equations) the complete logic.

BlockLogic
M1 run latchSet = I1, Reset = I2 + I3
Q3 green lampQ3 = M1
T1 on-delay 5 sInput = M1; Q1 = T1
T2 off-delay 5 sInput = M1; Q2 = T2 · /I3 (runs with the line and 5 s after, but an overload cuts it at once)
Q4 red lampQ4 = I3

I/O table (5 marks), latch with both stops (5), infeed on-delay (5), packer off-delay with the overload cut-out (7), lamps (3). Start order uses the on-delay and stop order uses the off-delay.

Scenario 6 · 25 marks

Pallet layer counter

Boxes are stacked on a pallet, 6 boxes per layer and 4 layers per pallet. Use only these LOGO!-style blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay. Inputs: I1 Start, I2 Stop, I3 box sensor (one pulse per box), I5 Reset (pushbuttons: pressed = 1). Outputs: Q1 box conveyor, Q2 layer pusher, Q3 pallet-full lamp, Q4 green lamp.

  1. Start latches the line on; Stop switches it off. The green lamp shows the line is on.
  2. The conveyor runs while the line is on, the layer is not complete and the pallet is not full.
  3. When 6 boxes have been counted the layer is complete: the pusher operates for 2 s and the layer counter is cleared.
  4. After 4 layers the pallet is full: the full lamp comes on and the line waits for Reset, which clears everything.
Show memo

Make an I/O table and draw (or write as equations) the complete logic.

BlockLogic
M1 run latchSet = I1, Reset = I2
Q4 green lampQ4 = M1
C1 up counter, preset 6 (boxes)Cnt = I3, Reset = T1 output + I5; output = layer complete
T1 on-delay 2 sInput = C1
Q2 pusherQ2 = C1 · /T1 (on for the 2 s)
C2 up counter, preset 4 (layers)Cnt = T1 output, Reset = I5; Q3 = C2 (pallet full)
Q1 conveyorQ1 = M1 · /C1 · /C2

I/O table (5 marks), latch and green lamp (3), box counter (4), pusher timing (4), layer counter chained from the timer (5), conveyor conditions (4). T1 resets C1, so T1's output is only on for one scan: that single pulse is what C2 counts. A pallet that is already full keeps the conveyor stopped until I5.

Method for every scenario: first list every input and output, then describe the behaviour of each output in words, then wire it using only the blocks the paper allows. The logic here is hand-checked, not run in LOGO! Soft Comfort, and the scenarios are practice questions written from the lecture notes, not past papers.
