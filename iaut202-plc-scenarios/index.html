IAUT202 — PLC scenario practice (6 scenarios)

Six packaging and conveyor scenarios laid out like Question 3 of the make-up paper (25 marks each): scenario, I/O table, sequence of operation, timing, counter, STOP and RESET behaviour. Carton line, crate line, bottle capper, shrink-wrap tunnel, two-conveyor accumulator and pallet layer counter. Do each one on paper, then open the memo.

Scenario 1 · 25 marks

Carton packaging line

Scenario. Tins arrive on an infeed conveyor and are packed 12 to a carton. When a carton is full it is sealed, then carried away by a carton conveyor. A red lamp warns people while the carton conveyor is moving.

Input / Output Table. Use these reference designators in your program:

TypeReferenceDescription
InputI1START pushbutton
InputI2STOP pushbutton
InputI3Tin sensor (one pulse per tin)
InputI4Carton in position sensor
InputI5RESET pushbutton
OutputQ1Infeed conveyor
OutputQ2Carton conveyor
OutputQ3Sealer
OutputQ4Green lamp (line running)
OutputQ5Red lamp (carton conveyor moving)

Sequence of Operation

  1. Initial state: all outputs off and the tin counter is at 0.
  2. The operator presses START (I1). The line switches on and the green lamp (Q4) comes on.
  3. The infeed conveyor (Q1) runs only while the line is on, a carton is in position (I4) and the carton is not yet full.
  4. Each tin passing the tin sensor (I3) is counted. When 12 tins have been counted the carton is full and the infeed conveyor stops.
  5. When the carton is full the sealer (Q3) operates for 4 s.
  6. When sealing is complete the carton conveyor (Q2) runs for 5 s to take the carton away. While it runs the red lamp (Q5) flashes at 1 Hz.
  7. When the carton conveyor stops, the tin counter is reset ready for the next carton.

Timing Requirements

  • Sealing time: 4 seconds
  • Carton conveyor run time: 5 seconds
  • Red lamp flash: 0.5 s on, 0.5 s off (1 Hz)

Counter Requirements

  • Use a counter to count the tins.
  • Carton size = 12 tins. At 12 the carton is full.

STOP Behaviour

  • STOP (I2) switches the line off at once: the infeed conveyor and the green lamp go off.
  • A sealing or carton-removal sequence that has already started is allowed to finish.
  • The tin count is retained when STOP is pressed.

RESET Behaviour

  • RESET (I5) clears the tin counter at any time.
  • RESET does not by itself restart the line; START must be pressed.

Instructions

  • Develop this control system as a program in Siemens LOGO! Soft Comfort (or draw it by hand as function blocks).
  • Use only these blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay.
  • Clearly label all inputs, outputs, timers and counters using the reference designators in the table.

Q4 green lampQ4 = M1
Q1 infeedQ1 = M1 · I4 · /C1 · /M2 (C1 = counter output 'full', M2 = carton-out latch)
C1 up counter, preset 12Cnt = I3, Reset = I5 + T2 output; output = full

The flasher works because T3 comes on after 0.5 s, T4 comes on 0.5 s later and cuts T3 off, which cuts T4 off, so it repeats every 1 s. T2's output is one scan wide because it resets M2 and C1.

Scenario 2 · 25 marks

Bottle crate packing line

Scenario. Bottles are packed 24 to a crate. Two lamps show the state of the crate, and a crate conveyor removes a full crate.

Input / Output Table. Use these reference designators in your program:

TypeReferenceDescription
InputI1START pushbutton
InputI2STOP pushbutton
InputI3Bottle sensor (one pulse per bottle)
InputI4Crate in position sensor
InputI5RESET pushbutton
InputI6EMERGENCY STOP pushbutton
OutputQ1Bottle conveyor
OutputQ2Crate conveyor
OutputQ3Red lamp (crate full)
OutputQ4Amber lamp (crate nearly full)
OutputQ5Green lamp (line running)

Sequence of Operation

  1. Initial state: all outputs off and the bottle counters are at 0.
  2. The operator presses START (I1). The line switches on and the green lamp (Q5) comes on.
  3. The bottle conveyor (Q1) runs only while the line is on, a crate is in position (I4) and the crate is not full.
  4. From bottle 20 up to bottle 23 the amber lamp (Q4) is on.
  5. At bottle 24 the crate is full: the amber lamp goes off, the red lamp (Q3) comes on and the bottle conveyor stops.
  6. 3 s after the crate is full the crate conveyor (Q2) runs for 6 s to remove the crate.
  7. When the crate conveyor stops, both counters are reset ready for the next crate.

Timing Requirements

  • Delay before the crate conveyor starts: 3 seconds
  • Crate conveyor run time: 6 seconds

Counter Requirements

  • Use two counters on the bottle sensor: one with a preset of 20 and one with a preset of 24.

STOP Behaviour

  • STOP (I2) or EMERGENCY STOP (I6) switches the line off at once.
  • The bottle counters are retained.

RESET Behaviour

  • RESET (I5) clears both counters at any time.
  • RESET does not by itself restart the line; START must be pressed.

Instructions

  • Develop this control system as a program in Siemens LOGO! Soft Comfort (or draw it by hand as function blocks).
  • Use only these blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay.
  • Clearly label all inputs, outputs, timers and counters using the reference designators in the table.

Scenario 3 · 25 marks

Bottle capping station

Scenario. Bottles travel on a conveyor to a capping position. A sensor detects a bottle at the capping position, after which a solenoid-operated capper presses a cap onto the bottle. Bottles are capped in batches. When a full batch has been capped, the conveyor runs on briefly to clear the last bottle, then stops and a Batch Complete lamp comes on.

Input / Output Table. Use these reference designators in your program:

TypeReferenceDescription
InputI1START pushbutton
InputI2STOP pushbutton
InputI3Bottle sensor (at the capping position)
InputI4RESET pushbutton
OutputQ1Conveyor motor
OutputQ2Capper
OutputQ3Batch Complete lamp

Sequence of Operation

  1. Initial state: all outputs are off, the bottle counter is at 0 and the Batch Complete lamp is off.
  2. The operator presses START (I1). The conveyor motor (Q1) starts.
  3. When a bottle reaches the capping position the bottle sensor (I3) activates and the conveyor stops.
  4. After a settling delay of 1 s the capper (Q2) extends and presses the cap on for 2 s.
  5. When the capping time has elapsed the capper retracts and the conveyor resumes, carrying the capped bottle away. A capped bottle must not be capped a second time while it is still in front of the sensor.
  6. Each time a bottle completes the capping process a counter increases by 1.
  7. When the counter reaches 8 (a full batch) the Batch Complete lamp (Q3) switches on and no further bottles may be capped. The conveyor runs for 3 extra seconds to clear the last bottle, and then stops.
  8. The operator presses RESET (I4) to clear the counter and switch off the lamp. START must be pressed again for the next batch.

Timing Requirements

  • Settling delay: 1 second
  • Capping time: 2 seconds
  • Conveyor run-on (batch clear) delay: 3 seconds

Counter Requirements

  • Use a counter to count each successfully capped bottle.
  • Batch size = 8 bottles.

STOP Behaviour

  • STOP (I2) must immediately switch off the conveyor motor and the capper, including during the 3 second run-on.
  • The bottle counter value is retained when STOP is pressed.
  • The system will not restart automatically; START must be pressed.

RESET Behaviour

  • RESET (I4) clears the counter and switches off the Batch Complete lamp.
  • RESET does not by itself restart the conveyor.

Instructions

  • Develop this control system as a program in Siemens LOGO! Soft Comfort (or draw it by hand as function blocks).
  • Use only these blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay.
  • Clearly label all inputs, outputs, timers and counters using the reference designators in the table.

BlockLogic
M1 run latch (reset-dominant)Set = I1, Reset = I2 + T4 output
C1 up counter, preset 8Cnt = T2 output (a capping cycle has just ended), Reset = I4; Q3 = C1
T4 on-delay 3 sInput = C1 (run-on; its output resets M1)
M2 'already capped' latchSet = T2 output, Reset = inverted I3 (the bottle has left the sensor)
T1 on-delay 1 sInput = M1 · I3 · /M2 · /C1

Marks: I/O table (5), run latch and run-on timer (5), counter and Q3 (4), settling and capping timers with the one-capping-per-bottle latch (7), conveyor and capper outputs (4). Read Q1 as: run while the line is on, but stop when a bottle is at the sensor, has not yet been capped, and the batch is not complete. STOP reaches M1, so Q1 and Q2 drop together; RESET goes only to the counter. The logic pattern was checked with a time-step script (8 caps, run-on, STOP, RESET); not run in LOGO! Soft Comfort.

Scenario 4 · 25 marks

Shrink-wrap tunnel

Scenario. Packs pass through a heated shrink-wrap tunnel. The tunnel must be hot before packs enter, and it must be cooled by a fan after the heater is switched off.

Input / Output Table. Use these reference designators in your program:

TypeReferenceDescription
InputI1START pushbutton
InputI2STOP pushbutton
InputI3Pack sensor (one pulse per pack leaving)
InputI4RESET pushbutton
OutputQ1Tunnel conveyor
OutputQ2Heater
OutputQ3Cooling fan
OutputQ4Batch lamp

Sequence of Operation

  1. Initial state: all outputs off and the pack counter is at 0.
  2. The operator presses START (I1). The heater (Q2) comes on.
  3. The tunnel conveyor (Q1) starts 3 s after the heater so that the tunnel is hot first.
  4. The cooling fan (Q3) runs while the heater is on and for 10 s after the heater goes off.
  5. Packs leaving the tunnel are counted while the conveyor runs. After 50 packs the batch lamp (Q4) comes on until RESET is pressed.

Timing Requirements

  • Heater-to-conveyor delay: 3 seconds
  • Fan run-on after the heater goes off: 10 seconds

Counter Requirements

  • Use a counter to count packs, gated by the conveyor running.
  • Batch size = 50 packs.

STOP Behaviour

  • STOP (I2) switches the conveyor and the heater off at once.
  • The fan keeps running for its 10 second run-on.
  • The pack count is retained.

RESET Behaviour

  • RESET (I4) clears the counter and the batch lamp.
  • RESET does not restart the line.

Instructions

  • Develop this control system as a program in Siemens LOGO! Soft Comfort (or draw it by hand as function blocks).
  • Use only these blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay.
  • Clearly label all inputs, outputs, timers and counters using the reference designators in the table.
Show memo

Make an I/O table and draw (or write as equations) the complete logic.

BlockLogic
M1 run latchSet = I1, Reset = I2
Q2 heaterQ2 = M1
T1 on-delay 3 sInput = M1; Q1 = T1 (drops the moment M1 drops)
T2 off-delay 10 sInput = Q2; Q3 = T2 output (on with the heater and 10 s after)
C1 up counter, preset 50Cnt = I3 · Q1, Reset = I4; Q4 = C1

Marks: I/O table (5), latch and heater (4), conveyor delay (5), fan off-delay (5), counter with the gate and reset (6). The off-delay is the key block: an on-delay cannot keep an output on after its input has gone.

Scenario 5 · 25 marks

Two-conveyor accumulator

Scenario. Two conveyors in series, the second feeding a packer. They start and stop in a set order so that product never piles up.

Input / Output Table. Use these reference designators in your program:

TypeReferenceDescription
InputI1START pushbutton
InputI2STOP pushbutton
InputI3Overload (stays 1 while an overload exists)
OutputQ1Infeed conveyor
OutputQ2Packer conveyor
OutputQ3Green lamp (line on)
OutputQ4Red lamp (overload)

Sequence of Operation

  1. Initial state: all outputs off.
  2. The operator presses START (I1). The line switches on and the green lamp (Q3) comes on.
  3. The packer conveyor (Q2) runs first and the infeed conveyor (Q1) follows 5 s later.
  4. On stopping, the infeed conveyor stops at once and the packer conveyor runs 5 s longer to clear the line.
  5. An overload (I3) stops both conveyors at once. The red lamp (Q4) is on while the overload exists.

Timing Requirements

  • Infeed start delay after the packer: 5 seconds
  • Packer run-on after stopping: 5 seconds

STOP Behaviour

  • STOP (I2) switches the line off: the infeed stops at once and the packer runs on for 5 s.
  • An overload stops both conveyors immediately.

RESET Behaviour

  • There is no RESET; the overload input stays 1 until the fault is cleared, and START must be pressed again.

Instructions

  • Develop this control system as a program in Siemens LOGO! Soft Comfort (or draw it by hand as function blocks).
  • Use only these blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay.
  • Clearly label all inputs, outputs, timers and counters using the reference designators in the table.
Show memo

Make an I/O table and draw (or write as equations) the complete logic.

BlockLogic
M1 run latchSet = I1, Reset = I2 + I3
Q3 green lampQ3 = M1
T1 on-delay 5 sInput = M1; Q1 = T1
T2 off-delay 5 sInput = M1; Q2 = T2 · /I3 (runs with the line and 5 s after, but an overload cuts it at once)
Q4 red lampQ4 = I3

Marks: I/O table (5), latch with both stops (5), infeed on-delay (5), packer off-delay with the overload cut-out (7), lamps (3). Start order uses the on-delay and stop order uses the off-delay.

Scenario 6 · 25 marks

Pallet layer counter

Scenario. Boxes are stacked on a pallet, 6 boxes per layer and 4 layers per pallet. A pusher moves each completed layer onto the pallet.

Input / Output Table. Use these reference designators in your program:

TypeReferenceDescription
InputI1START pushbutton
InputI2STOP pushbutton
InputI3Box sensor (one pulse per box)
InputI5RESET pushbutton
OutputQ1Box conveyor
OutputQ2Layer pusher
OutputQ3Pallet full lamp
OutputQ4Green lamp (line running)

Sequence of Operation

  1. Initial state: all outputs off and both counters at 0.
  2. The operator presses START (I1). The line switches on and the green lamp (Q4) comes on.
  3. The box conveyor (Q1) runs while the line is on, the layer is not complete and the pallet is not full.
  4. When 6 boxes have been counted the layer is complete: the pusher (Q2) operates for 2 s and the layer is cleared for the next one.
  5. Each completed layer is counted. After 4 layers the pallet is full: the full lamp (Q3) comes on and the conveyor stops until RESET.

Timing Requirements

  • Pusher time: 2 seconds

Counter Requirements

  • Count boxes with one counter (6 per layer) and layers with a second counter (4 per pallet).

STOP Behaviour

  • STOP (I2) switches the line off at once.
  • Both counts are retained.

RESET Behaviour

  • RESET (I5) clears both counters and the full lamp.
  • START must be pressed again.

Instructions

  • Develop this control system as a program in Siemens LOGO! Soft Comfort (or draw it by hand as function blocks).
  • Use only these blocks: relay coil, inverted output, make and break contacts, on-delay, off-delay, up counter, latching relay.
  • Clearly label all inputs, outputs, timers and counters using the reference designators in the table.
