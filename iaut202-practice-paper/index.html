1.4 A closed-loop control system is one that: [1]

Answer: D. Closed-loop systems feed the measured output back and compare it with the set-point. The difference (the error) drives the controller.

4.3 Name the three wrist motions of an industrial robot and briefly describe each. [3]

Show memo

Roll (rotation about the axis of the arm, a twisting motion), pitch (up and down tilting) and yaw (left and right swinging). Together they orient the end effector. (1 mark each.)

4.4 Differentiate between the accuracy and the repeatability of an industrial robot. [2]

Show memo

Repeatability: the ability to return to a previously taught position; Re = ±3σ (1). Accuracy: the ability to place the end effector at the desired controlled location in the work space; single axis Ac = CR/2 + 3σ (1).

4.5 What is the difference between a gripper and a tool as an end effector? Give one example of each. [2]

Show memo

A gripper holds and moves an object (mechanical or vacuum gripper); a tool performs an operation on the work part (welding gun, spray gun, spindle). (1 for the difference, 1 for both examples.)

4.6 Explain the difference between leadthrough programming and textual (computer) programming of a robot. [2]

Show memo

Leadthrough: the operator teaches positions by moving the arm (or using a teach pendant) through the work cycle and the controller stores and plays them back (1). Textual: the program is written as text commands (Move, Set, Speed, Wait, Open, Close, Loop) on a computer, giving better sensor, logic and communication abilities and offline programming without factory downtime (1).

Construct a pneumatic circuit, using double-acting cylinders, to achieve the following sequence (in series): B+ A+ B- C+ A- C-

The following conditions apply:

  • One push button (Start) activates one complete cycle.
  • Only use limit switches with normally open contacts.

  • A lamp must turn on once the cycle is complete.
  • The circuit design must use the cascading method.

The circuit diagram must be NEATLY hand-drawn (pen) and labelled, including valve port numbers, solenoid labels and limit switch positions. Marks will be deducted for every missing label on the drawing and for untidy work.

(a) Divide the sequence into groups. (b) Give the set and reset condition of every group relay. (c) Give the condition that energises every solenoid, including the timer if there is one. (d) State which sensors are pressed at rest. (e) Describe how you would draw and label the circuit. [24]

Robotics theory

4.1 Differentiate between the rotational (R), twisting (T) and revolving (V) joints. [6]

Show memo

All three are rotational motion; they differ in where the axis of rotation is. R: the axis is perpendicular to both links (2). T: the axis is parallel to the links, so the link twists about its own length (2). V: the input link is parallel to the axis of rotation and the output link is perpendicular to it (2).

  3. Articulated (jointed-arm) robot: TRR: a twisting base and two rotational joints; the common 6-axis robot (UR cobots); welding, painting, general handling.
  4. SCARA robot: Two rotating horizontal links and a vertical sliding rod (R V O); stiff vertically; assembly and palletising.
