Question 1 · 20 marks

Theory: control, PLCs and logic

Answer all questions in short sentences. (No pneumatics or robotics in this part.)

Define open-loop control and give one example. [2]

Show memo

Control with no feedback: the controller acts and nothing checks the result (1). Example: a toaster running for a set time, or a fan on a fixed timer (1).

State two differences between logic control and sequence control. [2]

Show memo

Logic control: output depends only on the present inputs, no memory, no time dependence. Sequence control: uses timers/counters to change outputs, usually open-loop and repeating in a cycle. (1 mark per correct difference.)

List the five levels of automation from the lowest to the highest. [2]

Show memo

1 sensor/actuator, 2 field (machine), 3 control (cell), 4 area management, 5 production management. (2 marks for all five in order, 1 for 3 correct.)

Describe the three steps of a PLC scan cycle. [2]

Show memo

1) Read (scan) the inputs into memory. 2) Execute the user program once using those inputs. 3) Update the outputs from the results. Then repeat. (Marks for steps in order.)

Convert the binary number 101101 to decimal. [2]

Show memo

32 + 0 + 8 + 4 + 0 + 1 = 45. (1 for working, 1 for answer.)

Draw the truth table of a 2-input AND gate and state the Boolean expression. [2]

Show memo

Q = A · B. Outputs for AB = 00, 01, 10, 11: 0, 0, 0, 1. (1 for expression, 1 for table.)

Explain how a latching (set/reset) relay works. [2]

Show memo

A pulse on Set turns the output on and it stays on after the pulse ends; a pulse on Reset turns it off. If both are on, the dominant input decides (reset-dominant: output off).

Differentiate between an on-delay and an off-delay timer. [2]

Show memo

On-delay: the output turns on after the input has been on for the preset time and drops when the input drops. Off-delay: the output turns on immediately with the input and stays on for the preset time after the input drops.

What is the difference between an event-driven and a time-driven change? Give one example of each. [2]

Show memo

Event-driven: caused by something that happens in the process (a limit switch senses a part). Time-driven: caused by the clock or a time lapse (a bell sounds at the start of a shift). (1 definition + example each.)

Differentiate between a normally open (NO) and a normally closed (NC) contact. [2]

Show memo

NO: open at rest, closes when actuated/energised. NC: closed at rest, opens when actuated/energised.

Question 1 · 20 marks

Theory: control, PLCs and logic

Answer all questions in short sentences. (No pneumatics or robotics in this part.)

Define closed-loop control and give one example. [2]

Show memo

Control that uses feedback: the output is measured and compared with the set-point, and the error drives the controller (1). Example: an oven with a thermostat (1).

State the three conditions under which open-loop control is acceptable. [2]

Show memo

The actions are simple; the actuating function is very reliable; the opposing reaction forces are small enough to ignore. (2 marks for three, 1 for two.)

Name the two common sequencing devices and say what each does. [2]

Show memo

Timer: switches an output on or off at preset times. Counter: counts electrical pulses and stores the count (outputs change when the preset is reached).

What is the purpose of safety monitoring? Name two responses a safety system can make. [2]

Show memo

To detect hazards and protect people and equipment (1). Responses: stop the system, sound an alarm, reduce speed (any two, 1).

Convert decimal 77 to binary. [2]

Show memo

77 = 64 + 8 + 4 + 1 = 1001101. (1 for working, 1 for answer.)

Draw the truth table of a 2-input OR gate and state the Boolean expression. [2]

Show memo

Q = A + B. AB = 00, 01, 10, 11 gives 0, 1, 1, 1.

What is the purpose of an interlock in PLC programming? [2]

Show memo

It prevents two actions that must not happen together (for example forward and reverse on one motor) or blocks an action until a condition is safe, by putting a contact of one output in the other's rung.

Explain what a counter's reset input does. [2]

Show memo

It clears the stored count back to zero and switches the counter output off, so counting can start again.

Differentiate between polling and an interrupt. [2]

Show memo

Polling: the PLC checks each input in turn during its scan. Interrupt: an event forces the program to stop and run a special routine immediately.

Differentiate between a sensor and an actuator. Give one example of each. [2]

Show memo

A sensor measures or detects something in the process and sends a signal in (limit switch, photoelectric sensor). An actuator receives a signal and does something to the process (motor, valve, lamp). (1 for each difference with example.)

Pneumatics: complete the sequence

A packing machine uses three double-acting cylinders A, B and C, each with end sensors X0 (retracted) and X1 (extended) and a double-solenoid 5/2 valve (A+ = Y1, A- = Y2, B+ = Y3, B- = Y4, C+ = Y5, C- = Y6). The sequence is C+ A+ C- B+ A- B-. A Start button begins one cycle and all cylinders are retracted at rest. Use the electrical cascade method.

(a) Divide the sequence into groups. (b) Give the set and reset condition of every group relay. (c) Give the condition that energises every solenoid. (d) State which sensors are pressed at rest and show the order of the moves. [24]

Show memo

(a) Groups. A new group starts as soon as a cylinder letter would repeat: [C+ A+] | [C- B+ A-] | [B-]. That is 3 groups, so 3 group relays K1 to K3.

(b) Relays. Each relay latches itself (hold contact) and is switched off by the next group's relay, so only one group is live at a time.

(d) Checks. At rest all cylinders are retracted, so A0, B0, C0 are pressed (that includes B0 for Start). Two opposite solenoids of one cylinder (e.g. Y1 and Y2) are never on together because the groups switch them at different times. Order of moves from the simulation: C+ A+ C- B+ A- B-.

Reference

The five joint symbols (own drawings)

L and O slide (translational). R, T and V rotate. R: axis perpendicular to the links. T: axis parallel to the links. V: input link parallel to the axis, output link perpendicular.
