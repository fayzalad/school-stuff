Discrete, binomial and Poisson

Q1Discrete, binomial and Poisson

The table gives P(X=0)=0.15, P(X=1)=?, P(X=2)=0.40, P(X=3)=0.25 and P(X=4)=0.05. What is P(X=1)?

  1. a)0.35
  2. b)0.15
  3. c)0.85
  4. d)1.00
  5. e)None of the above

Answer: b)

All the probabilities in a distribution add up to 1. The four known values add to 0.85, so the missing one is 1 − 0.85 = 0.15.

Trap: Picking 0.85 (the sum of what you already have) instead of the amount needed to reach 1.

Q2Discrete, binomial and Poisson

A random variable X has P(0)=0.15, P(1)=0.15, P(2)=0.40, P(3)=0.25, P(4)=0.05. Find E[X].

  1. a)2.00
  2. b)2.19
  3. c)0.85
  4. d)1.90
  5. e)None of the above

Answer: d)

E[X] = Σ x·P(x) = 0(0.15) + 1(0.15) + 2(0.40) + 3(0.25) + 4(0.05) = 0 + 0.15 + 0.80 + 0.75 + 0.20 = 1.90.

Trap: Adding the x values or dividing by 5 instead of multiplying each x by its probability.

Q3Discrete, binomial and Poisson

Same distribution: P(0)=0.15, P(1)=0.15, P(2)=0.40, P(3)=0.25, P(4)=0.05. Find V[X].

  1. a)4.80
  2. b)1.90
  3. c)1.19
  4. d)1.09
  5. e)None of the above

Answer: c)

V[X] = Σx²·P(x) − μ². Σx²·P(x) = 0.15 + 1.60 + 2.25 + 0.80 = 4.80. μ² = 1.90² = 3.61. So V[X] = 4.80 − 3.61 = 1.19.

Trap: Stopping at 4.80 (that is E[X²], not the variance), or giving 1.09, which is the standard deviation √1.19.

Q4Discrete, binomial and Poisson

Same distribution: P(0)=0.15, P(1)=0.15, P(2)=0.40, P(3)=0.25, P(4)=0.05. Find P(1 ≤ X < 3).

  1. a)0.55
  2. b)0.65
  3. c)0.40
  4. d)0.90
  5. e)None of the above

Answer: a)

1 ≤ X < 3 includes 1 and 2, but not 3. So P = P(1) + P(2) = 0.15 + 0.40 = 0.55.

Trap: Including X = 3 (which gives 0.65). Check the sign: '<' excludes the number, '≤' includes it.

Q5Discrete, binomial and Poisson

Which of these is NOT an assumption of the binomial distribution?

  1. a)Each trial is independent
  2. b)Each trial has only two outcomes
  3. c)The chance of success must be exactly 0.5
  4. d)The chance of success is the same on every trial
  5. e)None of the above

Answer: c)

A binomial needs a fixed number of trials, independent trials, two outcomes per trial and the same p each time. The chance p can be any value, such as 0.3 or 0.94.

Trap: Thinking p = 0.5 is a rule. It is only a special case.

Q6Discrete, binomial and Poisson

X ~ BI(8, 0.25). Find P(X = 2).

  1. a)0.3115
  2. b)0.0865
  3. c)0.2076
  4. d)0.1569
  5. e)None of the above

Answer: a)

P(X = x) = C(n,x) · p^x · (1−p)^(n−x). C(8,2) = 28, 0.25² = 0.0625, 0.75⁶ = 0.1780. So 28 × 0.0625 × 0.1780 = 0.3115.

Trap: Forgetting the C(n,x) term, or swapping p and 1−p.

Q7Discrete, binomial and Poisson

X ~ BI(4, 0.1). Find P(X ≥ 1).

  1. a)0.6561
  2. b)0.0656
  3. c)0.3439
  4. d)0.1000
  5. e)None of the above

Answer: c)

'At least one' is the complement of 'zero': P(X ≥ 1) = 1 − P(X = 0) = 1 − 0.9⁴ = 1 − 0.6561 = 0.3439.

Trap: Answering 0.6561, which is P(X = 0), the chance of none.

Q8Discrete, binomial and Poisson

X ~ BI(50, 0.2). Find E[X] and V[X].

  1. a)E = 10, V = 2
  2. b)E = 50, V = 10
  3. c)E = 0.2, V = 0.16
  4. d)E = 10, V = 8
  5. e)None of the above

Answer: d)

E[X] = np = 50 × 0.2 = 10. V[X] = np(1 − p) = 10 × 0.8 = 8.

Trap: Forgetting the (1 − p) part of the variance, or using p alone as the mean.

Q9Discrete, binomial and Poisson

Which of these is a binomial situation?

  1. a)The time until the first customer arrives
  2. b)The number of defective bulbs among 12 bulbs tested (each bulb is defective or not)
  3. c)The number of calls to a call centre in one hour
  4. d)The rainfall in mm in one month
  5. e)None of the above

Answer: b)

A binomial counts successes in a fixed number n of trials, and each trial has two outcomes. The 12 bulbs give a fixed n.

Trap: Calls in an hour have no fixed n, so that is Poisson.

Q10Discrete, binomial and Poisson

Breakdowns happen at an average of 2 per week (Poisson, μ = 2). Find P(X = 0).

  1. a)0.1804
  2. b)0.8647
  3. c)0.1353
  4. d)0.2707
  5. e)None of the above

Answer: c)

P(X = x) = μ^x e^(−μ) / x!. For x = 0: e^(−2) = 0.1353.

Trap: 0.2707 is P(X = 1), not P(X = 0).

Q11Discrete, binomial and Poisson

Same Poisson distribution (μ = 2). Find P(X ≤ 1).

  1. a)0.1353
  2. b)0.4060
  3. c)0.2707
  4. d)0.5940
  5. e)None of the above

Answer: b)

P(X ≤ 1) = P(0) + P(1) = 0.1353 + 0.2707 = 0.4060.

Trap: 0.5940 is P(X ≥ 2) = 1 − 0.4060. Read the ≤ sign carefully.

Q12Discrete, binomial and Poisson

Which of these is a Poisson variable?

  1. a)The number of defective bulbs in a box of 12
  2. b)The number of text messages received in one hour
  3. c)The number of heads in 10 coin tosses
  4. d)The number of students who pass out of 30
  5. e)None of the above

Answer: b)

Poisson counts events over a period, area or length, with no fixed upper limit. The other three have a fixed number of trials n, so they are binomial.

Trap: Any count with a fixed number of trials is binomial, not Poisson.

Q13Discrete, binomial and Poisson

Which statement about the Poisson distribution is true?

  1. a)Its mean is np and its variance is np(1 − p)
  2. b)It has two parameters, n and p
  3. c)Its mean and variance are both equal to μ
  4. d)It is used for proportions
  5. e)None of the above

Answer: c)

For a Poisson variable, E[X] = V[X] = μ. The np and np(1 − p) formulas belong to the binomial.

Trap: Mixing up the binomial and Poisson formulas.

Q14Discrete, binomial and Poisson

Calls arrive at an average of 0.5 per minute. Find the probability of exactly 5 calls in 10 minutes.

  1. a)0.5000
  2. b)0.1755
  3. c)0.0067
  4. d)0.2650
  5. e)None of the above

Answer: b)

The rate must match the time period: μ = 0.5 × 10 = 5. Then P(X = 5) = 5⁵ e^(−5) / 5! = 0.1755.

Trap: Using μ = 0.5 without scaling to 10 minutes. 0.0067 is e^(−5), which is P(X = 0) for μ = 5.

Normal distribution

Q15Normal distribution

Which statement about a continuous normal variable X is true?

  1. a)The distribution is skewed to the right
  2. b)P(X = a) is a positive height on the curve
  3. c)The total area under the curve is 2
  4. d)P(X = a) = 0 for any single value a
  5. e)None of the above

Answer: d)

The normal is continuous, so a single exact value has probability 0. We find probabilities for intervals, not single points.

Trap: Thinking the height of the curve at a point is a probability.

Q16Normal distribution

Find P(Z < 1.5) for the standard normal.

  1. a)0.8413
  2. b)0.5000
  3. c)0.0668
  4. d)0.9332
  5. e)None of the above

Answer: d)

Read the row 1.5 and the column 0.00 in the Z table: P(Z < 1.5) = 0.9332.

Trap: 0.0668 is P(Z > 1.5), the other tail.

Q17Normal distribution

Find P(Z > −1.2) for the standard normal.

  1. a)0.8849
  2. b)0.1151
  3. c)0.1587
  4. d)0.7699
  5. e)None of the above

Answer: a)

The normal is symmetric, so P(Z > −1.2) = P(Z < 1.2) = 0.8849.

Trap: 1 − 0.8849 = 0.1151 is P(Z < −1.2), the wrong side.

Q18Normal distribution

X ~ N(50, 16). Find P(X > 58).

  1. a)0.0228
  2. b)0.9772
  3. c)0.0456
  4. d)0.1587
  5. e)None of the above

Answer: a)

16 is the variance, so σ = 4. z = (58 − 50) / 4 = 2. P(Z > 2) = 0.0228.

Trap: Using 16 as the standard deviation, or 0.0456, which is both tails.

Q19Normal distribution

X ~ N(100, 25). Find the value x such that P(X < x) = 0.90.

  1. a)106.41
  2. b)112.82
  3. c)103.29
  4. d)110.00
  5. e)None of the above

Answer: a)

σ = √25 = 5. From the Z table, P(Z < z) = 0.90 gives z = 1.282. So x = 100 + 1.282 × 5 = 106.41.

Trap: Using σ = 25 directly, which gives 112.82.

Q20Normal distribution

When can the normal approximation to the binomial be used?

  1. a)p = 0.5 exactly
  2. b)n < 30
  3. c)n ≥ 1000 only
  4. d)np ≥ 5 and n(1 − p) ≥ 5
  5. e)None of the above

Answer: d)

The check is both np ≥ 5 and n(1 − p) ≥ 5. A large n on its own is not enough if p is very small.

Trap: Thinking a large n is enough by itself.

Q21Normal distribution

Which binomial can be approximated by the normal distribution?

  1. a)BI(12, 0.05)
  2. b)BI(10, 0.1)
  3. c)BI(100, 0.01)
  4. d)BI(40, 0.3)
  5. e)None of the above

Answer: d)

BI(40, 0.3): np = 12 and n(1 − p) = 28, both ≥ 5. BI(10, 0.1) has np = 1; BI(12, 0.05) has np = 0.6; BI(100, 0.01) has np = 1. Each fails.

Trap: BI(100, 0.01) has a big n, but np is only 1, so it fails the check.

Sampling distributions and the CLT

Q22Sampling distributions and the CLT

The sample mean x̄ is approximately normal for large n, even when the population is not normal. This is because of the:

  1. a)Chebyshev's inequality
  2. b)Central Limit Theorem
  3. c)Normality of the population
  4. d)Law of Large Numbers
  5. e)None of the above

Answer: b)

The CLT says the sampling distribution of x̄ becomes approximately normal for large n, whatever the population shape. The Law of Large Numbers says x̄ gets close to µ, but says nothing about its shape.

Trap: Mixing up the LLN (closeness to µ) with the CLT (shape).

Q23Sampling distributions and the CLT

µ = 60, σ = 10, n = 25. Find P(x̄ > 63).

  1. a)0.0668
  2. b)0.1587
  3. c)0.3085
  4. d)0.9332
  5. e)None of the above

Answer: a)

SE = σ / √n = 10 / 5 = 2. z = (63 − 60) / 2 = 1.5. P(Z > 1.5) = 1 − 0.9332 = 0.0668.

Trap: Using σ = 10 instead of the standard error SE = 2.

Q24Sampling distributions and the CLT

σ = 12, n = 36. Find the standard error of x̄.

  1. a)2
  2. b)12
  3. c)0.33
  4. d)6
  5. e)None of the above

Answer: a)

SE = σ / √n = 12 / √36 = 12 / 6 = 2.

Trap: 0.33 = 12/36 (dividing by n instead of √n).

Q25Sampling distributions and the CLT

p = 0.4, n = 100. Find the standard error of p̂.

  1. a)0.400
  2. b)0.024
  3. c)0.240
  4. d)0.049
  5. e)None of the above

Answer: d)

SE(p̂) = √(p(1 − p) / n) = √(0.24 / 100) = √0.0024 = 0.049.

Trap: 0.240 is p(1 − p) before dividing by n, and 0.024 is a misplaced decimal point.

Q26Sampling distributions and the CLT

As the sample size n increases, the standard error of x̄:

  1. a)doubles
  2. b)stays the same
  3. c)decreases
  4. d)increases
  5. e)None of the above

Answer: c)

SE = σ / √n. A bigger n gives a smaller SE. Doubling n shrinks the SE by a factor of √2, not by half.

Trap: Thinking doubling n halves the SE. It only divides it by √2.

Q27Sampling distributions and the CLT

µ = 30, σ = 8, n = 16. The sampling distribution of x̄ has mean and standard deviation:

  1. a)30 and 8
  2. b)2 and 30
  3. c)30 and 0.5
  4. d)30 and 2
  5. e)None of the above

Answer: d)

The mean of x̄ is µ = 30. The SD of x̄ (the standard error) is 8 / √16 = 2.

Trap: 0.5 = σ / n (wrong; the square root is needed).

Q28Sampling distributions and the CLT

Population mean 15, SD 5, n = 100. Find P(x̄ > 16).

  1. a)0.1587
  2. b)0.8413
  3. c)0.0456
  4. d)0.0228
  5. e)None of the above

Answer: d)

SE = 5 / √100 = 0.5. z = (16 − 15) / 0.5 = 2. P(Z > 2) = 0.0228.

Trap: Using σ = 5 as the SE, which gives a different z.

Confidence intervals

Q29Confidence intervals

x̄ = 52, σ = 6, n = 36. Find a 95% CI for µ (σ known).

  1. a)[50.04, 53.96]
  2. b)[49.00, 55.00]
  3. c)[51.02, 52.98]
  4. d)[46.08, 57.92]
  5. e)None of the above

Answer: a)

SE = 6 / √36 = 1. z = 1.96. So 52 ± 1.96 × 1 = [50.04, 53.96].

Trap: Using a z value other than 1.96 for 95%, or using 6 as the SE.

Q30Confidence intervals

n = 16, x̄ = 20, s = 4. Find a 95% CI for µ (σ unknown).

  1. a)[18.040, 21.960]
  2. b)[17.869, 22.131]
  3. c)[19.107, 20.893]
  4. d)[16.000, 24.000]
  5. e)None of the above

Answer: b)

σ is unknown, so use t with df = 15: t = 2.131. SE = 4 / √16 = 1. So 20 ± 2.131 × 1 = [17.869, 22.131].

Trap: Using z = 1.96 (the σ-known formula), which gives [18.040, 21.960].

Q31Confidence intervals

n = 200, 60 successes. Find a 90% CI for p.

  1. a)[0.2200, 0.3800]
  2. b)[0.2933, 0.3067]
  3. c)[0.2700, 0.3300]
  4. d)[0.2467, 0.3533]
  5. e)None of the above

Answer: d)

p̂ = 60 / 200 = 0.30. SE = √(0.30 × 0.70 / 200) = 0.0324. z = 1.645. So 0.30 ± 1.645 × 0.0324 = 0.30 ± 0.0533 = [0.2467, 0.3533].

Trap: Leaving out z and using ±1 SE, which gives [0.2700, 0.3300].

Q32Confidence intervals

What does a 95% confidence level mean?

  1. a)95% of the sample values lie inside the interval
  2. b)There is a 95% probability that µ is inside this particular interval
  3. c)The sample mean is correct 95% of the time
  4. d)If we repeated the sampling many times, about 95% of intervals built this way would contain µ
  5. e)None of the above

Answer: d)

The 95% describes the method, not one interval. Once calculated, a particular interval either contains µ or it does not.

Trap: Saying 'there is a 95% chance µ is in this interval'. µ is fixed, not random.

Q33Confidence intervals

Same data. The confidence level goes from 90% to 99%. The interval:

  1. a)gets wider
  2. b)gets narrower
  3. c)stays the same
  4. d)gets half as wide
  5. e)None of the above

Answer: a)

Higher confidence needs a bigger z (1.645 becomes 2.576), which makes the interval wider.

Trap: Thinking more confidence means a narrower interval.

Q34Confidence intervals

Which change makes the CI for µ narrower (σ known)?

  1. a)increase the sample size n
  2. b)decrease n
  3. c)increase σ
  4. d)increase the confidence level
  5. e)None of the above

Answer: a)

The margin of error is z × σ / √n. A bigger n makes √n bigger and the margin smaller. The other three make it wider.

Trap: Thinking more confidence gives a narrower interval (it gives a wider one).

Q35Confidence intervals

n = 10, s² = 4. Find a 95% CI for σ².

  1. a)[0.189, 1.333]
  2. b)[1.000, 4.000]
  3. c)[2.700, 19.023]
  4. d)[1.892, 13.331]
  5. e)None of the above

Answer: d)

df = 9. Lower = (n−1)s² / χ²(9; 0.975) = 36 / 19.023 = 1.892. Upper = (n−1)s² / χ²(9; 0.025) = 36 / 2.700 = 13.331.

Trap: Taking the χ² table values as the answer, or dividing 36 by 100 by mistake.

Q36Confidence intervals

n = 25. Which values are used in a 95% CI for σ²?

  1. a)z at 0.975
  2. b)t with df = 24, at 0.025
  3. c)χ² with df = 24, at 0.975 and 0.025
  4. d)χ² with df = 25, at 0.05
  5. e)None of the above

Answer: c)

The CI for σ² uses the chi-square distribution with df = n − 1 = 24, with both tails at 0.025. t and z are for means.

Trap: Using t or z, which are for means, not variances.

Q37Confidence intervals

Sample size for a mean: σ = 12, margin of error 3, 95% confidence. Find n.

  1. a)16
  2. b)62
  3. c)61
  4. d)96
  5. e)None of the above

Answer: b)

n = (z σ / e)² = (1.96 × 12 / 3)² = (7.84)² = 61.47. Always round UP, so n = 62.

Trap: Rounding down to 61. Sample sizes are always rounded up.

Q38Confidence intervals

Sample size for a proportion: margin of error 0.05, 95% confidence, no estimate of p. Find n.

  3. c)384
  4. d)385

Answer: d)

With no estimate of p, use p(1 − p) = 0.25. n = (1.96 / 0.05)² × 0.25 = 384.16, which rounds up to 385.

Q39Confidence intervals

n = 25, x̄ = 10, s = 2.4. Find a 99% CI for µ.

  1. a)[7.500, 12.500]
  2. b)[9.012, 10.988]
  3. c)[8.601, 11.399]
  4. d)[8.657, 11.343]
  5. e)None of the above

df = 24, t = 2.797. SE = 2.4 / 5 = 0.48. Margin = 2.797 × 0.48 = 1.343. So 10 ± 1.343 = [8.657, 11.343].

Q40Confidence intervals

With σ known, if the sample size is quadrupled (n × 4), the margin of error:

  1. a)stays the same
  2. b)quadruples
  3. c)halves
  4. d)doubles
  5. e)None of the above

Answer: c)

Margin = z σ / √n. √4 = 2, so the margin is divided by 2.

Hypothesis testing

Q41Hypothesis testing

A manager wants evidence that the mean delivery time is MORE than 30 minutes. Which is H1?

  1. a)µ ≠ 30
  2. b)µ ≥ 30
  3. c)µ > 30
  4. d)µ < 30
  5. e)None of the above

Answer: c)

H1 is the claim we want evidence for, so it is 'more than 30'. The opposite, H0, is µ ≤ 30.

Trap: Writing µ ≥ 30, which includes equality. Equality belongs to H0.

Q42Hypothesis testing

What is a Type I error?

  1. a)Accepting H0 when H0 is true
  2. b)Failing to reject H0 when H0 is false
  3. c)Rejecting H0 when H0 is true
  4. d)Choosing the wrong test statistic
  5. e)None of the above

Answer: c)

A Type I error is a false alarm. Its probability is α, the significance level. Failing to reject a false H0 is a Type II error.

Trap: Mixing up Type I (false alarm, α) and Type II (missed effect).

Q43Hypothesis testing

x̄ = 52, µ0 = 50, σ = 8, n = 64. Two-tailed test at 5%. Find z and decide.

  1. a)z = 0.25 and reject H0
  2. b)z = 1.00 and reject H0
  3. c)z = 2.00 and reject H0
  4. d)z = 2.00 and do not reject H0
  5. e)None of the above

Answer: c)

z = (52 − 50) / (8 / √64) = 2 / 1 = 2.00. The critical values are ±1.96. Since |2.00| > 1.96, reject H0.

Trap: Forgetting to divide by √n (8/8 gives z = 0.25).

Q44Hypothesis testing

The two-tailed p-value is 0.0455 and α = 0.05. What is the decision?

  1. a)Reject H0
  2. b)The test is inconclusive
  3. c)Do not reject H0
  4. d)Accept H0
  5. e)None of the above

Answer: a)

p = 0.0455 < α = 0.05, so reject H0. We never 'accept' H0; the result is either reject or fail to reject.

Trap: Saying 'accept H0' instead of 'fail to reject H0'.

Q45Hypothesis testing

p-value = 0.12 and α = 0.05. What is the conclusion?

  1. a)Do not reject H0: there is insufficient evidence against H0
  2. b)H0 is proven true
  3. c)H1 is proven true
  4. d)Reject H0
  5. e)None of the above

Answer: a)

0.12 > 0.05, so we fail to reject H0. That means not enough evidence against it. It does not prove H0.

Trap: Thinking 'do not reject' proves H0 true.

Q46Hypothesis testing

H0: p = 0.5. n = 100, 60 successes. Two-tailed test at 5%. Find z and decide.

  1. a)z = 0.20 and reject H0
  2. b)z = 1.00 and do not reject H0
  3. c)z = 2.00 and do not reject H0
  4. d)z = 2.00 and reject H0
  5. e)None of the above

Answer: d)

p̂ = 0.60. Under H0, SE = √(0.5 × 0.5 / 100) = 0.05. z = (0.60 − 0.50) / 0.05 = 2.00. Since 2.00 > 1.96, reject H0.

Trap: Using p̂ in the SE of a test. A test uses p0 (the value in H0).

Q50Hypothesis testing

What does 'fail to reject H0' mean?

  1. a)H0 has been proven true
  2. b)H1 has been proven false
  3. c)There is not enough evidence to conclude H1 is true
  4. d)The sample was too small
  5. e)None of the above

Answer: c)

We never prove H0. Failing to reject only means the data do not give strong enough evidence against H0.

Trap: Saying 'H0 is true' after a non-significant result.
